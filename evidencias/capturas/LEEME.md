# Capturas del examen

Guarda las capturas de interfaz en esta carpeta.

- 00_docker_estado.png: estado o mensaje de error de Docker Desktop, si el motor no inicia. Es un diagnóstico; no prueba la ejecución del examen.
- 01_docker_servidor.png: Docker Desktop > Containers, proyecto coopac-core y contenedor sr_bd en ejecución. Capturar cuando el servidor esté levantado.
- 02_docker_imagen.png: Docker Desktop > Images, imagen postgres con etiqueta 16.
- 03_github_repositorio.png: repositorio si084-caso-coopac con INFORME.md y la carpeta evidencias después de subirlo.
- 04_github_etiqueta.png: etiqueta examen-u1 y los archivos del repositorio en esa etiqueta.
- 05_informe_pdf.png: vista previa del informe al guardar como PDF.

El examen exige las salidas TXT de P1 a P7 y SHA256SUMS.txt. Las capturas son complementarias; no sustituyen esos archivos. Las capturas de GitHub y del PDF se toman al llegar a los pasos 4 y 5.
